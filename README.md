# Bottle Defect Detection using Deep Learning

## 📌 Project Overview
This project is a real-time bottle defect detection system using Deep Learning. 
The system uses a pre-trained model to analyze images captured from the system camera and classify bottles as:

- ✅ Non-Defective
- ❌ Defective

The model also provides prediction confidence (accuracy percentage).

---

## 🚀 Features
- Real-time image capture using system camera
- Pre-trained deep learning model integration
- Classification: Defective / Non-Defective
- Prediction confidence score display
- Simple and user-friendly execution

---

## 🛠️ Tech Stack
- Python
- OpenCV (Camera Integration)
- PyTorch / TensorFlow
- NumPy
- Matplotlib

---

## 📷 How It Works
1. The system accesses the computer camera.
2. Captures an image of the bottle.
3. The image is preprocessed.
4. The trained model predicts:
   - Defective
   - Non-Defective
5. The prediction confidence score is displayed.
